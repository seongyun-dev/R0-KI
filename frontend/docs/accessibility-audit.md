# 접근성 점검 보고서 — 글자 크기 · 색 대비

> 작성일 2026-07-21 · 대상 `frontend` · 측정 환경 1920×1030, 목업 데이터(`VITE_USE_MOCKS` 기본값)
>
> **배경**: 주 사용자가 고령의 경비원이라는 점을 고려해, 화면의 모든 텍스트를 대상으로 글자 크기와 색 대비를 실측했다.

## 요약

전 화면에서 **동일한 문제가 반복**된다. 개별 화면의 실수가 아니라 **디자인 토큰 자체가 기준 미달**이기 때문이다.

- `--muted`(#8a8a8a)와 `--subtle`(#b6b6b6)이 사이드바·표 헤더·시각·보조 문구 전반에 쓰이는데, 각각 **3.45:1**과 **2.03:1**로 기준(4.5:1)에 미달한다.
- 상태색(`--success`/`--warning`/`--danger`)을 **글자색으로** 쓰는 상태 태그가 **2.86~3.33:1**로 화면에서 가장 안 보인다. 경비원이 가장 먼저 봐야 할 정보라 우선순위가 가장 높다.
- 보조 텍스트 상당수가 **12px**이고, 대시보드 지도 구역 이름은 **8.5px**이다.

## 측정 방법

- 각 화면에서 텍스트를 가진 모든 엘리먼트를 순회하며 `getComputedStyle`로 실제 렌더링된 글자 크기와 색을 읽고, 조상 방향으로 실제 배경색을 찾아 WCAG 2.1 공식으로 명암비를 계산했다.
- 판정 기준(WCAG 2.1 AA)
  - 일반 텍스트 **4.5:1**
  - 큰 텍스트(24px 이상, 또는 18.66px 이상이면서 굵게) **3:1**
- **한계**: 배경이 `linear-gradient`인 요소는 자동 계산에서 제외했다(아래 "별도 확인" 참고). 상세 페이지(`/app/events/:id`, `/app/patrol/:id`, `/app/robots/:id`), `/app/robots/new`, `/app/map`, 온보딩 2~5단계는 순회하지 않았으나 **동일한 공용 컴포넌트를 쓰므로 같은 문제가 있을 것으로 본다.**

## 심각도별 문제 목록

### 1순위 — 상태 태그 (가장 중요한 정보인데 가장 안 보임)

`StatusBadge` / `Tag`. 12px에 상태색을 글자색으로 사용.

| 표시 | 색 | 대비 | 기준 |
|---|---|---|---|
| `[ 충전중 ]` `[ 처리중 ]` | `--warning` #d97706 | **2.86:1** | 미달 |
| `[ 순찰중 ]` `[ 처리완료 ]` | `--success` #16a34a | **3.00:1** | 미달 |
| `[ 대기 ]` | `--muted` #8a8a8a | **3.06:1** | 미달 |
| `[ 긴급 ]` | `--danger` #e5484d | **3.33:1** | 미달 |

상태를 **색으로만** 구분하는 구조라, 색이 흐리면 색각이상·노안 사용자에게는 구분 수단이 사라진다.

### 2순위 — 토큰 `--subtle` (#b6b6b6, 2.03:1)

거의 읽히지 않는 수준. 사용처:

- 사이드바 `알림` 메뉴(비활성 항목)
- `/signup` 아파트단지 입력칸 플레이스홀더 `아파트단지를 검색해 선택하세요`

### 3순위 — 토큰 `--muted` (#8a8a8a, 3.45:1)

가장 널리 쓰이는 보조색. 사용처:

- 사이드바 메뉴 라벨(`순찰관리`, `이벤트관리`, `로봇관리`, `통계`), `로그아웃`
- 표 헤더(`ID`, `순찰ID`, `전체 로봇` 등)
- 시각 표시 `14:32`, `12:15:45` (12px, 배경에 따라 **2.94:1**까지 떨어짐)
- 카드 부제 `실시간 지도`, `신뢰도 · 경과`
- `/login` `계정이 없으신가요?`, `/signup` 입력 도움말 `4~20자 영문/숫자`

### 4순위 — 액센트를 글자색으로 사용 (#e0532a, 3.86:1)

- 링크·액션 `상세 →`, `전체 이벤트 →`, `⤢ 지도 확대 보기`
- `/signup` 필수 항목 표시 `*`

### 5순위 — 글자 크기

| 대상 | 현재 |
|---|---|
| 대시보드 지도 구역 이름(`주차장 A`, `분리수거장` 등) | **8.5px** |
| 상태 태그, 표 헤더, 시각, 배터리 `78 %`, 버튼 일부(`검색`, `CSV 내보내기`, `로봇 등록`) | **12px** |

### 별도 확인 필요 — 그라디언트 배경 버튼

`로봇 등록` 등 그라디언트 배경 버튼은 자동 측정에서 제외됐다. 다만 액센트 단색(#e0532a) 위 흰 글자를 계산하면 **약 3.57:1**로, 12px 일반 텍스트 기준 4.5:1에 미달한다. 실제 그라디언트 값 기준으로 재확인이 필요하다.

## 권고 조치

### A. 토큰 교체 (효과가 가장 큼 — 전 화면 일괄 적용)

`src/styles/tokens.css`. 괄호 안은 흰 배경 기준 명암비.

| 토큰 | 현재 | 권고 |
|---|---|---|
| `--muted` | #8a8a8a (3.45) | **#6b6b6b (4.84)** |
| `--subtle` | #b6b6b6 (2.03) | **#767676 (4.54)** |
| `--success` | #16a34a (3.00) | **#15803d (5.01)** |
| `--warning` | #d97706 (2.86) | **#b45309 (5.02)** |
| `--danger` | #e5484d (3.33) | **#b91c1c (6.47)** |

액센트는 브랜드색이라 그대로 두고, **글자·링크에 쓸 때만** 이미 존재하는 `--accent-deep`(#b8431e, **5.44:1**)을 쓰도록 바꾸는 것을 권한다. 배경으로 쓰는 `--accent`는 유지.

> 상태색을 바꾸면 `-soft` 배경 변형과의 조합도 함께 확인해야 한다. 태그는 soft 배경 위에 글자가 올라가므로 흰 배경 기준값보다 대비가 낮아진다.

### B. 최소 글자 크기 규칙

- 본문·라벨 **16px 이상**
- 보조 텍스트 **14px 이상** (현재 12px인 표 헤더·시각·태그)
- 지도 구역 이름 **12px 이상** (현재 8.5px)

### C. 색에만 의존하지 않기

상태 태그에 **아이콘이나 형태 차이**를 함께 주면, 색 구분이 어려운 사용자도 상태를 읽을 수 있다. 지금은 색과 대괄호 텍스트뿐이다.

### D. 터치·클릭 영역

랜딩 상단바에는 이미 적용했다(48px). 앱 화면의 버튼·표 행 액션도 **최소 44px** 확보를 권한다. 손떨림이 있는 사용자에게 실사용 차이가 크다.
