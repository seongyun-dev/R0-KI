# 시연 시나리오

확인 기준: 2026-08-10

서비스: `https://i15e103.p.ssafy.io/`
원본 대본: [Notion 시연 대본](https://app.notion.com/p/3b815fc50ec780a1aabacf548812c478)

## 1. 로그인 정보

```text
아이디: ssafy123
비밀번호: password123!
```

시연용 계정이다. 발표 전 로그인 가능 여부를 확인하고 브라우저 자동 저장은 사용하지 않는다.

## 2. 사전 준비

- Jetson, ESP32, 카메라와 로봇 전원을 켠다.
- 로봇이 출발 위치에 있고 장애물이 없는지 확인한다.
- 자동차, 쓰레기, 쓰러진 사람 역할을 대본 순서에 맞춰 준비한다.
- 서비스에 로그인한 뒤 대시보드에서 `R0-Ki` 상태가 `대기`인지 확인한다.
- 지도와 순찰 경로, 배터리, 실시간 탐지 영상 영역이 표시되는지 확인한다.
- 발표자와 장비 담당자는 `순찰 시작`을 누르는 시점을 사전에 맞춘다.

## 3. 전체 진행 순서

```text
랜딩 → 로그인 → 대시보드에서 순찰 시작
→ 차량 탐지 → 쓰레기 탐지 → 응급상황 처리
→ 순찰 자동 종료 → 순찰 보고서 확인
```

## 4. 화면별 시연 절차

### 0. 랜딩과 로그인

| 항목 | 내용 |
| --- | --- |
| 화면 | 랜딩 `/`, 로그인 `/login` |
| 클릭 위치 | 랜딩 중앙의 `관리자 로그인 →` → 로그인 화면 중앙 입력란 |
| 입력 | 아이디와 비밀번호 입력 후 `로그인` |
| 결과 | `/app` 대시보드로 이동하고 좌측 메뉴와 관제 지도가 표시됨 |

멘트:

> 원래 제가 직접 순찰을 돌아야 하는데, 오늘은 로키에게 맡겨보겠습니다. 자, 어디 한번 잘하고 있나 볼까요?

### 1. 순찰 시작

1. 좌측 메뉴에서 `대시보드`를 선택한다.
2. 지도 아래의 `R0-Ki · 대기` 로봇 카드를 누른다.
3. `순찰 시작` 확인창에서 로봇명과 배터리를 확인한다.
4. 장비 담당자의 준비 신호를 받은 뒤 창 오른쪽 아래 `순찰 시작`을 누른다.

기대 화면:

- 로봇 상태가 `대기`에서 `순찰중`으로 변경된다.
- 지도에 위치와 이동 경로가 갱신된다.
- `실시간 탐지 영상`이 순찰 화면으로 전환된다.
- 이벤트 이력에는 이번 순찰에서 새로 발견한 이벤트가 최신순으로 추가된다.

주의: 마지막 `순찰 시작` 버튼은 실제 로봇을 움직인다. 리허설에서도 현장 준비가 끝난 뒤 누른다.

### 2. 자동차 탐지

현장 담당자가 로봇 진행 방향에 자동차를 제시한다.

멘트:

> 여기 차량이 한 대 있네요. 주차구역이 아닌 곳에 세워져 있습니다. 로키가 차량을 발견하고 바로 알려줬습니다.

화면 확인:

1. 대시보드 `이벤트 이력`에서 이번 시각에 생성된 `불법주차` 또는 `미등록 차량` 항목을 찾는다.
2. 해당 이벤트 행을 클릭한다.
3. 이벤트 상세에서 `증거 이미지`, `유형`, `탐지 날짜`, `위치`, `탐지 로봇`, `신뢰도`를 차례로 보여준다.
4. 좌측 메뉴의 `대시보드`를 눌러 관제 화면으로 돌아간다.

화면의 이벤트 명칭은 AI 판정 결과에 따라 `불법주차` 또는 `미등록 차량`으로 표시될 수 있다. 번호판 문자와 문자 발송 결과는 현재 이벤트 상세 화면에 별도 필드로 표시되지 않으므로, 증거 이미지와 이벤트 유형·위치를 중심으로 설명한다.

### 3. 쓰레기 탐지

현장 담당자가 다음 탐지 지점에 쓰레기를 제시한다.

멘트:

> 누가 통행로에 쓰레기를 버리고 갔네요. 현장 이미지와 발견 위치까지 바로 확인할 수 있습니다.

화면 확인:

1. 대시보드 `이벤트 이력`에 새로 추가된 `쓰레기` 항목을 클릭한다.
2. 이벤트 상세의 증거 이미지와 위치를 보여준다.
3. 신뢰도와 현재 처리 상태가 `탐지`로 기록된 것을 확인한다.
4. 좌측 `대시보드`를 눌러 돌아간다.

차량과 쓰레기 이벤트는 발표 흐름을 끊지 않도록 상세 화면에서 상태를 변경하지 않고 조회만 한다.

### 4. 쓰러진 사람 긴급상황

현장 담당자가 쓰러진 사람 상황을 연출한다.

멘트:

> 잠깐만요. 여기 사람 한 분이 쓰러져 있는 것 같습니다. 이런 상황은 대시보드에 긴급 알림으로 바로 표시됩니다.

화면 동작:

1. 대시보드 중앙에 `[ 긴급 알림 ]` 모달이 자동으로 표시된다.
2. 모달에서 `응급상황`, 위치, 로봇, 신뢰도와 경과시간을 보여준다.
3. 모달 오른쪽 아래 `즉시 확인 →`을 누른다.
4. 이벤트 상세의 `처리 상태` 영역에서 `처리중`을 누른다.
5. 현장 확인 연기를 진행한다.
6. 같은 영역에서 `처리완료`를 누른다.
7. `처리 완료` 창의 메모에 `현장 확인 완료`를 입력하고 오른쪽 아래 `완료 처리`를 누른다.

멘트:

> 위치와 현장 이미지를 확인했습니다. 일단 처리 중으로 바꾸겠습니다. 현장을 확인했으니 처리 완료로 기록하겠습니다.

기대 화면:

- 상태가 `탐지 → 처리중 → 처리완료` 순서로 변경된다.
- 처리 담당자와 처리 시각이 기록된다.
- 처리완료 이후에는 상태 버튼이 잠기고 메모만 수정할 수 있다.

### 5. 순찰 종료

로봇이 마지막 도착지까지 이동하면 순찰이 자동으로 끝난다.

멘트:

> 지정된 경로를 모두 이동하면 순찰이 자동으로 종료됩니다. 오늘 순찰도 잘 끝났습니다.

화면 확인:

1. 대시보드에 `순찰 완료` 모달이 표시된다.
2. 모달 오른쪽 아래 `확인`을 누른다.
3. 로봇 상태가 다시 `대기`로 바뀌는지 확인한다.

자동 종료가 늦어질 때만 로봇 카드의 `순찰 종료`를 사용한다. 정상 시연에서는 도착지 완료에 따른 자동 종료를 보여준다.

### 6. 순찰 보고서

1. 좌측 메뉴에서 `순찰 관리`를 누른다.
2. `순찰 이력` 표의 맨 위에서 방금 종료된 시각과 이벤트 건수를 확인한다.
3. 해당 행의 가장 오른쪽 `상세`를 누른다.
4. 상세 화면에서 다음 순서로 설명한다.

| 위치 | 확인 내용 |
| --- | --- |
| 상단 | 순찰 ID, Robot, 완료 상태 |
| 이동 경로 지도 | 실제 이동 경로와 차량·쓰레기·응급 이벤트 위치 |
| 순찰 지점 기록 | 경유지와 이벤트 목록, 처리 상태 |
| 하단 `AI 요약` | 시작·종료 시각, 주요 이벤트와 처리 결과 요약 |
| 상단 오른쪽 | `PDF 다운로드`로 보고서 저장 |

멘트:

> 순찰 시간과 이동 경로, 발견한 이벤트와 처리 결과가 모두 기록되어 있습니다. AI가 오늘 순찰 내용도 요약했습니다. 이제 로키가 순찰뿐 아니라 보고서 작성까지 도와줍니다.

필요하면 이벤트 목록에서 차량, 쓰레기, 응급상황 항목을 눌러 각 상세 화면으로 다시 이동할 수 있다.

## 5. 시연 중 문제 발생 시

### 긴급 모달이 뜨지 않을 때

1. 좌측 `이벤트 관리`를 누른다.
2. 유형 필터에서 `응급상황`을 선택한다.
3. 시연 시작 이후 생성된 가장 최신 이벤트의 오른쪽 `상세`를 누른다.
4. 이벤트 상세에서 `처리중`, `처리완료` 순서로 진행한다.

### 이벤트가 여러 개 보일 때

- 이벤트 ID를 외우지 말고 탐지 시각과 현재 순찰의 위치를 기준으로 고른다.
- 예전 이벤트가 아닌 시연 시작 이후 생성된 항목을 선택한다.

### 순찰 보고서가 바로 보이지 않을 때

- `순찰 관리`에서 기간을 `오늘`로 선택한다.
- 페이지를 한 번 새로고침하고 가장 최근 종료 시각의 행을 확인한다.
- AI 요약 생성이 끝나지 않았으면 잠시 기다린 뒤 상세 화면을 새로고침한다.

### 실시간 영상이 나오지 않을 때

- 발표는 지도 위치와 이벤트 증거 이미지로 이어간다.
- 장비 담당자는 Jetson 카메라와 영상 터널 상태를 별도로 확인한다.
